# NPPS4 v5.10：Wrapper 监听地址、文本搜索与测试兑换码

本版以 v5.09 服装完整生命周期版本为基线，只调整 Android Wrapper 的监听地址体验、编辑器可用性，以及新增测试用兑换码。没有改动 v5.09 已实现的服装、饰品、活动剧情、好友互通、Ranking 或数据迁移状态机。

## 1. 默认监听端口恢复为 51376

Android Wrapper 的默认监听地址恢复为：

```text
127.0.0.1:51376
```

Kotlin 前台服务、Android Python 启动桥、状态检测与健康检查的 Android 默认值均统一为 51376。

桌面版 NPPS4 的普通 CLI/Docker 示例仍保留上游自己的 8080 默认值；本次要求针对 Android Wrapper，因此没有擅自改变桌面部署约定。

> 以前交付的 GL 测试 APK，其加密 `server_info.json` 默认仍是 `127.0.0.1:8080`。继续使用该 APK 时，可在首次启动服务器前把 Wrapper 端口改为 8080；新输入会永久保存。若要让 GL APK 也默认使用 51376，需要单独重建该测试 APK。

## 2. Host 与 Port 永久保存

监听 Host 与 Port 现在保存于 Android SharedPreferences：

```text
server_endpoint / host
server_endpoint / port
```

保存时机包括：

- 输入形成合法 Host 与 1–65535 端口时自动保存；
- 从主界面切换到文本编辑页时保存；
- App 退到后台时保存；
- 点击启动或重启服务器时再次保存。

因此切换页面、关闭 App、重新启动 App 或覆盖升级源码编译的 APK 后，都不会把已保存的合法地址重置成默认值。

## 3. 服务运行时锁定监听地址

点击“启动服务器”或“重启服务器”后，Host 与 Port 文本框立即锁定。状态轮询还会根据 Python 服务的真实状态继续维持锁定：

```text
preparing / migrating / initializing_db / starting / running / stopping
```

状态区域显示的是 Python 服务实际报告的 `host` 和 `port`，而不是文本框里尚未生效的草稿值。只有服务已停止、空闲或启动失败后，地址输入框才重新开放。

这意味着修改文本不再制造“状态指示器已经换端口，但实际服务仍监听旧端口”的假象；运行中的 Uvicorn 监听地址也不会被 GUI 热修改。

## 4. 所有文本编辑/日志子页增加搜索

`ConfigEditorActivity` 是所有配置文件、`server_data.json`、External Python 文件和错误日志的统一子页面。现在每个此类页面顶部都包含：

- 搜索文本框；
- “上一个”；
- “下一个”。

输入字符串后会自动跳转到第一个匹配；按钮可继续向前或向后查找。搜索不区分大小写，命中后会：

- 选中匹配文本；
- 自动滚动到对应行；
- 显示行号及“当前匹配 / 总匹配数”。

原有可拖动的横向和纵向滚动条保持不变。

## 5. 新兑换码 LOVEARROWSHOOT

新增可重复使用的兑换码：

```text
LOVEARROWSHOOT
```

它不是一次性累加，而是把低于目标值的测试资源补到目标值，因此反复输入不会不断膨胀数据库。当前目标包括：

| 资源 | 目标数量 |
|---|---:|
| 金币 | 99,999,999 |
| 好友点 | 99,999,999 |
| 免费 Loveca | 99,999 |
| 付费 Loveca | 99,999 |
| LP | 9,999 |
| 训练体力及上限 | 99 |
| 社员持有上限 | 5,000 |
| 待机室上限 | 5,000 |
| 好友上限 | 1,000 |
| 当前 Profile 的普通道具、票券、材料 | 各 9,999 |
| LP 恢复道具 | 各 9,999 |
| 贴纸/交换货币 | 各 9,999 |
| 可拆卸 SIS | 各 99 |
| 支援/强化社员 | 各 100 |

兑换码按当前 CN 或 GL Profile 的 Master Data 枚举资源，不会向客户端发放该 Profile 不认识的 Master ID。

它不会自动制造所有可收藏普通卡、饰品或服装。那些对象有拥有记录、唯一 ID、容量、图鉴和客户端资源依赖，批量生成全部收藏品会制造大量重复记录并影响真实功能测试；本码提供的是进行招募、合成、强化、商店、饰品、Live 等测试所需的通用资源。

### 已有 Android 工作区升级

`server_data.json` 是用户可编辑文件，Wrapper 正常升级时不会覆盖它。本版在工作区准备阶段只做一次保守合并：

- 保留用户所有自定义字段和兑换码；
- 若缺少 `LOVEARROWSHOOT`，从内置模板追加；
- 已存在时不重复添加；
- JSON 无效时不覆盖，继续交由正常校验流程报告错误。

## 6. 迁移与兼容性

- 不需要数据库 Schema/Alembic 迁移。
- 不需要清除账号、好友、剧情、饰品或服装数据。
- Android 与 PC 的共享 Python 服务端树保持一致；PC 版同样拥有 `LOVEARROWSHOOT`。
- Android GUI 的 Host/Port 持久化和锁定只存在于 Android Wrapper。
