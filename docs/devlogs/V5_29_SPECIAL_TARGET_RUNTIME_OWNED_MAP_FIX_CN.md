# v5.29：专用饰品目标卡运行时/共享库存映射修复

本版从 v5.24 基线重新实现，保留 v5.24 的饰品发放、升满、制作、装备与转移行为。

修复点：

1. 兑换码 WebView 从认证 Session 恢复真实 CN/GL Profile；
2. 目标卡不再只取静态当前 Profile 目录，而是合并当前运行时 `accessory_special_m`；

5. 写入后重新查询玩家数据库，兑换结果显示目标总数、验证数、运行时映射数、跨 Profile 映射数及具体缺失 ID。
